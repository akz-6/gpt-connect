# C++ Programação Competitiva

Biblioteca rápida de C++ para treino e consulta em competições.

## Navegação
- `01-fundamentos/`: sintaxe básica
- `02-containers/`: vector, string, map, set
- `03-estruturas/`: stack, queue, priority_queue
- `04-algoritmos/`: sort, busca binária, prefix sum, dois ponteiros
- `05-grafos/`: BFS e DFS
- `06-recursao/`: recursão e backtracking
- `templates/`: esqueletos para começar rápido

> Objetivo: lembrar sintaxe e padrões. As soluções são exemplos autorais de treino, inspirados em técnicas comuns de programação competitiva.
