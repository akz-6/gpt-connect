# Referências externas de programação competitiva

Esta pasta organiza fontes externas para estudo e consulta.

Os repositórios abaixo são de seus respectivos autores e permanecem vinculados às fontes originais:

1. https://github.com/kinhosz/Algorithms/tree/master/Data%20structures
2. https://github.com/LiedsonLB/cpp-studies
3. https://github.com/joao-acw/progcomp
4. https://github.com/BrunoBReis/programacao-competitiva
5. https://github.com/Matunag/Questoes-cpp

## Como baixar localmente

Execute o script `baixar_referencias.sh` na raiz do projeto. Ele clona cada fonte para uma subpasta local em `referencias-externas/fontes/`.

Isso preserva a origem e o histórico de cada projeto, em vez de copiar o conteúdo de terceiros para dentro deste repositório sem uma licença explícita.

> Se algum autor disponibilizar uma licença que permita redistribuição, ou autorizar explicitamente a cópia, o conteúdo poderá ser importado conforme esses termos.
